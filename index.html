Le card sono pretokenizzate in fase di preparazione.

Come funziona. Per ogni pulsante il browser usa token SentencePiece preparati con il deck N5 originale, poi esegue text conditioner, FlowLM e Mimi con ONNX Runtime Web. La pausa viene aggiunta al PCM fra segmenti, non al testo.

Primo caricamento: i file INT8 sono voluminosi; è richiesta una connessione per il runtime JS dal CDN. Safari iOS usa WebAssembly CPU a thread singolo. La qualità italiana è ancora sperimentale. Per GitHub Pages consulta DEPLOY_GITHUB_PAGES.md; per l'offline completo occorre distribuire e memorizzare tutti i file del runtime e dei modelli.
